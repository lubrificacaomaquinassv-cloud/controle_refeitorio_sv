PUBLICAR ATUALIZAÇÃO
--------------------
1. Copie App.py e sigcf_auth.py desta pasta para o GitHub
2. Atualize requirements.txt (inclui pandas)
3. Streamlit Cloud → Main file: App.py
4. Secrets: SUPABASE_URL, SUPABASE_KEY, APP_PIN

RODAR LOCAL
-----------
pip install -r requirements.txt
streamlit run App.py
